# پایش سلامت 💚

اپلیکیشن موبایل اندروید برای ثبت و پایش شاخص‌های سلامت شخصی با **رابط کاملاً فارسی**، **تقویم شمسی** و **چیدمان راست‌به‌چپ** — ساخته‌شده با Flutter.

## ویژگی‌ها

- **۸ شاخص سلامت:** قد، وزن، فشار خون (سیستولی/دیاستولی)، قند خون، اکسیژن خون (SpO2)، ضربان قلب، آب (لیوان)، قدم (حساس گام‌شمار گوشی)
- **محاسبات خودکار:** BMI با دسته‌بندی، کالری مصرفی پیاده‌روی (فرمول استاندارد MET)، مسافت تقریبی
- **۵ صفحه:** داشبورد (روز/هفته/ماه)، ثبت داده، تاریخچه، نمودارها، تقویم و تنظیمات
- **تقویم شمسی (جلالی):** انتخابگر تاریخ اختصاصی با علامت‌گذاری روزهای دارای رکورد
- **ثبت چندگانه:** چند رکورد برای یک شاخص در یک روز
- **فیلتر و مرتب‌سازی:** بر اساس نوع، بازه تاریخ شمسی و بازه زمانی روز (صبح/ظهر/عصر/شب)
- **نمودارها:** خطی، میله‌ای، دایره‌ای (توزیع زمانی) و ترکیبی (قدم + کالری) — امروز/هفته/ماه/همه
- **خروجی:** PDF (فارسی و راست‌به‌چپ)، Excel (xlsx) و پشتیبان JSON با بازیابی
- **ذخیره‌سازی محلی و امن:** SQLite روی خود گوشی + پشتیبان‌گیری دستی
- **یادآوری روزانه** ثبت آب و اهداف قابل تنظیم (آب/قدم)
- **تم روشن و تیره** با پالت سلامت (سبز/آبی/سفید) و فونت وزیرمتن

## دریافت APK

دو راه:

1. **بخش Releases:** فایل `app-release.apk` را از [آخرین Release](../../releases/tag/latest) دانلود کنید.
2. **بخش Actions:** وارد بیلد موردنظر شوید و آرتیفکت `health-monitor-apk` را دانلود کنید.

> هنگام نصب ممکن است پیام «منبع ناشناس» نمایش داده شود؛ برای نصب نسخه شخصی آن را تأیید کنید.
> مجوز «فعالیت بدنی» برای شمارش قدم از حساس گوشی لازم است.

## ساخت محلی

```bash
flutter --version   # 3.24.x پیشنهاد می‌شود
git clone https://github.com/<username>/health-monitor-app.git
cd health-monitor-app
flutter create . --platforms=android   # تولید اسکلت اندروید (در ریپو commit نشده)
flutter pub get
flutter build apk --release
# خروجی: build/app/outputs/flutter-apk/app-release.apk
```

## ساخت خودکار (CI)

پروژه شامل GitHub Actions است (`.github/workflows/build-apk.yml`):
با هر push به `main`، فایل APK نسخه Release ساخته شده و هم به آرتیفکت‌های Actions و هم به Release با برچسب `latest` آپلود می‌شود.

## ساختار پروژه

```
lib/
├── main.dart                  # نقطه شروع، تم و جهت RTL
├── theme.dart                 # پالت سبز-آبی سلامت
├── models/measurement.dart    # مدل داده
├── services/                  # SQLite، حساس گام‌شمار، خروجی PDF/Excel/پشتیبان
├── providers/                 # مدیریت وضعیت (Provider)
├── screens/                   # ۵ صفحه اصلی
├── utils/                     # تقویم شمسی، محاسبات سلامت، قالب‌بندی فارسی
└── widgets/                   # تقویم شمسی، کارت‌ها، اجزای مشترک
```
